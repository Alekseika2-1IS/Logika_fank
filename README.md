# Logika_fank — демоэкзамен (JavaFX)

Проект по заданию №01 «Отработать функциональную логику приложения».

## Что реализовано
- **Задание 1** — форма ввода/вывода: сложение, вычитание, умножение двух аргументов.
- **Задание 2** — форма со списком имён:
    - добавление только кнопкой (прямой ввод в список запрещён);
    - удаление кнопкой с изображением;
    - подсветка выбранного элемента;
    - навигация стрелками;
    - отмена последней вставки по Ctrl+Z;
    - нормализация: пробелы, регистр (ИнноКЕнТиЙ -> Иннокентий);
    - проверка на нетекстовые символы с модальным окном;
    - исключение дубликатов.

## Запуск
1. JDK 17 + IntelliJ IDEA.
2. Открыть проект, дождаться загрузки зависимостей Maven.
3. Run 'Main.main()'.

## Стек
Java 17, JavaFX 17, Maven.
